# Meet Catering - Website (ready for GitHub Pages)

Files included:
- index.html
- styles.css
- app.js

How to publish on GitHub Pages:
1. Create a repository named `meet-catering` (if you haven't already).
2. Upload these files to the repository root (commit to `main` branch).
3. On GitHub: Settings → Pages → Select branch `main` and root `/` → Save.
4. After a minute, your site will be live at: https://meetjoshi6551.github.io/meet-catering/

Optional (using git locally):
```
git init
git add .
git commit -m "Initial commit: Meet Catering site"
git branch -M main
git remote add origin https://github.com/meetjoshi6551/meet-catering.git
git push -u origin main
```
